# Security policy

## Supported versions

Only the [latest release](https://github.com/bve/OpenOSC/releases/latest) receives fixes.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through
[GitHub Security Advisories](https://github.com/bve/OpenOSC/security/advisories/new). Include the
device model, the firmware version and the steps to reproduce the problem.

You should receive a reply within two weeks. OpenOSC is maintained in spare time, so a fix may take
longer. You will be told when the issue is fixed and credited in the release notes unless you prefer
otherwise.

Relevant areas include the USB interfaces (USBTMC, CDC and SCPI command handling, the USB drive in
Recovery) and firmware image validation in Recovery.
